# Planificador Jagpino · Derecho UNED

Planificación del estudio del grado en Derecho de la UNED: plan diario, repasos rápidos, reparto de exámenes de febrero y calendario de PEC.

**Abrir e instalar la app:** https://costalceleste.github.io/planificador-jagpino/

Se instala como app en Android (Chrome), Windows (Chrome o Edge) e iPhone/iPad (Safari → Compartir → «Añadir a pantalla de inicio»). Los datos de cada estudiante se guardan solo en su dispositivo.
